A claim, and the thing that checks it

freshcart-backend allocates invoice numbers under contention. The claim is that the allocation is unique and gap-free, not a read-then-write that two callers can both win. The repository proves it: twenty-five allocators fire in parallel against a real MySQL instance in a container, and the test asserts the awarded set is exactly one to twenty-five. BerriAI/litellm

Stale spend counters kept returning HTTP 429 after a budget window had rolled over.

A production LLM gateway with more than fifty thousand stars. Resetting an end-user budget cleared the spend in Postgres but left the cached counter alive on other workers and replicas, so requests kept being rejected against a budget that had already reset. The fix invalidates the counter across the cache tier, and ships with dedicated regression tests and a documented two-replica reproduction.
